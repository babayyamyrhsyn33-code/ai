# هم‌نوشت | وبلاگ فارسی دسترس‌پذیر

وبلاگی ایستا، راست‌چین و موبایل‌پسند با لحن خودمانی و کنایه‌های بی‌آزار؛ منتشرشده با GitHub Pages و GitHub Actions.

## امکانات
- جست‌وجو و فیلتر موضوعی، نوشتهٔ پیشنهادی و نشانک‌های محلی
- پیوند اختصاصی هر نوشته از نوع `?post=slug`، مناسب کپی و اشتراک‌گذاری
- کپی پیوند نوشته از پنجرهٔ مطالعه
- پوستهٔ روشن/تیره، اندازهٔ متن، فاصلهٔ خطوط، کنتراست بالا و کاهش حرکت
- کنترل‌های صفحه‌خوان‌پسند، فوکوس واضح و چیدمان RTL
- پنل راهنمای انتشار در `/admin/`
- فرم انتشار مبتنی بر GitHub Actions؛ بدون ذخیرهٔ توکن در مرورگر
- `robots.txt`، `sitemap.xml` تولیدشده هنگام build، `llms.txt` و `manifest.webmanifest`
- اعتبارسنجی ورودی‌ها و escape کردن متن نوشته‌ها هنگام نمایش

## انتشار نوشته از گوشی
1. صفحهٔ [پنل انتشار](https://babayyamyrhsyn33-code.github.io/ai/admin/) را باز کن.
2. پیوند «رفتن به فرم انتشار امن» را انتخاب کن و وارد GitHub شو.
3. در صفحهٔ گردش‌کار **Publish a blog post**، گزینهٔ **Run workflow** را بزن.
4. عنوان، شناسهٔ انگلیسی کوتاه، دسته‌بندی، خلاصه، زمان مطالعه و متن را وارد کن.
5. برای جداکردن پاراگراف‌ها از `|||` استفاده کن. برای تیتر فرعی، یک بخش را با `### ` شروع کن.
6. اجرا را تأیید کن. گردش‌کار ورودی‌ها را بررسی می‌کند، نوشته را ثبت می‌کند و سایت دوباره منتشر می‌شود.
7. پس از موفقیت، نوشته با پیوندی مانند `https://babayyamyrhsyn33-code.github.io/ai/?post=my-new-post` در دسترس است.

شناسه باید فقط شامل حروف کوچک انگلیسی، عدد و خط تیره باشد؛ مثلاً `android-accessibility`. هر شناسه فقط یک بار استفاده می‌شود.

## چرا پنل انتشار به GitHub می‌رود؟
یک فرم مدیریتی که مستقیماً داخل سایت ایستا قرار بگیرد، برای نوشتن در مخزن به احراز هویت نیاز دارد. قرار دادن توکن GitHub در JavaScript عمومی ناامن است. بنابراین خود فرم انتشار در محیط احرازشدهٔ GitHub Actions اجرا می‌شود و پنل سایت راه ورود به آن را روشن و ساده می‌کند.

## محدودیت‌های صادقانه
- GitHub Actions و GitHub Pages جای بک‌اند دائمی نیستند.
- ورود کاربران سایت، دیدگاه مشترک، CAPTCHA سمت سرور، اعلان ایمیلی و نقش‌های چندمدیره هنوز فعال نیستند؛ برایشان باید سرویس امن سمت سرور اضافه شود.
- نشانک‌ها و تنظیمات فقط روی همان مرورگر ذخیره می‌شوند.
- پیوندهای نوشته به صورت پارامتر `?post=` هستند؛ نقشهٔ سایت در زمان build با نوشته‌های موجود به‌روز می‌شود.

## ساختار اصلی
- `index.html`: صفحهٔ اصلی
- `assets/app.js`: تعاملات و نوشته‌های اولیه
- `assets/community-posts.json`: نوشته‌های منتشرشده از پنل
- `admin/index.html`: پنل راهنمای انتشار
- `.github/workflows/publish-post.yml`: فرم و فرایند انتشار
- `.github/workflows/pages.yml`: اعتبارسنجی، تولید نقشهٔ سایت و انتشار
- `SECURITY.md`: مدل امنیتی و گزارش آسیب‌پذیری
