# هم‌نوشت | وبلاگ فارسی دسترس‌پذیر

یک وبلاگ ایستا و راست‌چین فارسی با تمرکز بر دسترس‌پذیری، خوانایی، حریم خصوصی و انتشار خودکار روی GitHub Pages.

## امکانات
- طراحی واکنش‌گرا برای موبایل و دسکتاپ
- پیمایش صفحه‌کلیدی، پیوند پرش به محتوای اصلی و فوکوس واضح
- جست‌وجو و فیلتر موضوعی نوشته‌ها
- پنجرهٔ خواندن متن و ذخیرهٔ نوشته برای بعد
- پوستهٔ روشن/تیره، اندازهٔ متن، فاصلهٔ خطوط، کنتراست بالا و کاهش حرکت
- بدون ورود، فرم دریافت اطلاعات شخصی یا ردیاب تبلیغاتی
- GitHub Actions برای بررسی فایل‌ها و انتشار خودکار

## انتشار
1. در مخزن وارد Settings → Pages شو.
2. در Build and deployment، گزینهٔ GitHub Actions را انتخاب کن.
3. پس از ثبت فایل‌ها در شاخهٔ main، گردش‌کار .github/workflows/pages.yml اجرا می‌شود.
4. وضعیت را در زبانهٔ Actions بررسی کن؛ پس از موفقیت، آدرس سایت در جزئیات deployment نمایش داده می‌شود.

## دیدگاه و ضداسپم
این نسخه ایستا است. دیدگاه عمومی داخل خود سایت فعال نیست؛ پیوند گفت‌وگو به GitHub Discussions می‌رود و لازم است Discussions در تنظیمات مخزن فعال شود. از فرم ساختگی برای دریافت رمز یا اطلاعات شخصی استفاده نمی‌کنیم.

برای دیدگاه عمومی، ورود کاربران، کپچا یا محدودسازی درخواست‌ها، یک سرویس سمت سرور یا سرویس دیدگاه معتبر لازم است. کد مرورگر به‌تنهایی نمی‌تواند احراز هویت یا مقابلهٔ قطعی با اسپم فراهم کند. هیچ کلید محرمانه‌ای را در فایل‌های عمومی سایت قرار نده.

## محدودیت‌ها
- نوشته‌ها در assets/app.js تعریف شده‌اند و تغییرشان نیازمند commit است.
- نشانک‌ها و تنظیمات فقط در مرورگر فعلی ذخیره می‌شوند.
- فونت Vazirmatn از Google Fonts بارگیری می‌شود و در صورت قطع دسترسی از فونت جایگزین استفاده می‌شود.
- هنوز پنل مدیریت، حساب کاربری، دیدگاه داخلی یا پایگاه داده وجود ندارد.
